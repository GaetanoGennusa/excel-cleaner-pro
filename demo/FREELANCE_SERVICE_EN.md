# Local Excel and CSV data cleaning

I can help organize small Excel and CSV datasets using a local Python application with reviewable cleaning rules. Services include whitespace cleanup, consistent column headings and text casing, explicit Italian or international number conversion, date normalization with an agreed format, and confirmed removal of exact duplicate rows.

Included: an initial review of one agreed dataset, a before/after preview, a cleaned Excel workbook, an issues sheet, an operation log, and a handover explaining unresolved values. Scope, file sizes, columns and acceptance criteria should be agreed before work begins. Uploaded files are processed locally without paid AI services or mandatory cloud accounts.

Limitations: ambiguous dates and uncertain matches require a client's decision. Missing values are not invented. Excel formulas, macros, charts, styling and complex workbook features are not preserved as an editable original workbook. Conversion of numeric Excel cells cannot recover leading zeros already lost in the source. Synthetic demonstrations do not guarantee results on client files.

Not included: accounting or legal validation, recovery of corrupted workbooks, web scraping, external system integrations, automated fuzzy merging, unlimited revisions, or unattended processing of arbitrary large files. Commercial delivery requires manual verification against the agreed source and acceptance criteria.
