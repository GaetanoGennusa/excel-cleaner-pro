# Product Catalog Spreadsheet Cleaning

I can clean and standardize a small product catalog supplied as a CSV or XLSX file, using agreed rules and a report that records what changed.

Included in the proposed starting scope:

- One file, one selected worksheet, up to 1,000 data rows and 20 columns.
- Whitespace cleanup and agreed text case for selected columns.
- Explicit Italian or international numeric formats and a chosen date format.
- Preservation of text identifiers, leading zeros and missing values.
- Removal of exact source duplicates only when explicitly authorized.
- A cleaned CSV and an XLSX report with data, issues, per-cell changes and settings.
- One revision limited to the original agreed requirements.

Before work starts, we agree on the columns, number and date conventions, duplicate criteria and expected deliverables. The source file and requirements need review before a price or delivery date can be confirmed.

Uncertain values remain visible for your decision. A repeated SKU may represent a valid variant; the tool does not decide which business record is correct. Product names and category case are changed only if agreed. The report does not certify product data, prices, stock quantities or tax treatment.

Not included: online-store upload, marketplace-specific schema mapping, merging catalogs, semantic matching, enrichment, translations, VBA/macros, accounting validation, formula or workbook-layout preservation, damaged-file repair, or recovery of identifiers already damaged in Excel. These need separate assessment.

The portfolio example contains entirely synthetic records. It is not past client work, a testimonial or evidence of financial results. Processing is local. Original uploads are not saved by the application, but XLSX generation uses local temporary XML files; successful export removes them, while crashes may leave remnants. Confidential files require an agreed handling and deletion process.

This is an unpublished service description. Manual acceptance checks and review of the particular dataset remain required before commercial delivery.
